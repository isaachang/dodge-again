# 历史测试与调试页面

这些文件随项目保留，方便后续维护，但尚未全部迁移至 v3.8。

- `engine.test.cjs`：早期规则回归。部分用例仍引用旧的护盾倒计时、血包概率和攻击调度，应按最新规则重写后再作为发布门槛。
- `browser-check.html`：基础浏览器流程检查，使用独立 QA 榜单；最新版本尚未重新运行。
- `growth-check.html`：历史成长/拾取场景。源文件注入匹配及护盾状态引用随版本变更已过时，需要同步维护。
- `shield-preview.html`：v3.6 护盾显示问题的隔离复现场景，禁用敌人和自动补给，仅用于查看护盾外观，不是正式游戏入口。

若要维护规则测试，需要 Node.js（测试使用其内置 `node:test`，无需 npm 依赖）。历史命令为：

```sh
node --test tests/engine.test.cjs
```

当前不承诺此命令通过。历史通过数量与当时验证条件见 `../TEST-REPORT.md`，不得将它们描述为 v3.8 全部通过。

# 再躲一下 · DODGE AGAIN

一款 **16:9、WASD 操作、只躲避不攻击**的浏览器生存小游戏。

敌人从四周分批登场，瞄准、释放技能后退场。你需要预判弹道、寻找空隙、争取补给，通过局内成长挑战自己的生存纪录。

**当前版本：v3.8 · 可试玩原型。** 排行榜保存在当前浏览器本机，不是在线共享榜单。项目使用原生 HTML、CSS 和 JavaScript，无前端框架、第三方运行依赖、账号系统或后端。

## 下载与运行

### 方式一：直接打开离线版

下载仓库中的 [`dist/dodge-again.html`](dist/dodge-again.html)，用桌面浏览器打开即可游玩，不需要安装开发工具。

也可以在 GitHub 点击 **Code → Download ZIP**，解压后打开该文件。建议使用 Chrome、Edge 或 Safari。文件模式下的成绩保存取决于浏览器存储策略，推荐下面的本地服务方式。

### 方式二：本地运行（推荐）

需要 Git（使用 ZIP 下载则不需要）以及 Python 3。无需执行 `npm install`。

```sh
git clone https://github.com/isaachang/dodge-again.git
cd dodge-again
python3 -m http.server 8765 --bind 127.0.0.1
```

Windows 可将最后一行换为：

```powershell
py -3 -m http.server 8765 --bind 127.0.0.1
```

打开 **http://127.0.0.1:8765/**。保持终端运行，按 `Ctrl+C` 停止服务。如果端口被占用，可将 `8765` 换成 `8766`，并访问对应地址。

仓库为私有时，克隆需要具有访问权限的 GitHub 账号。此本地服务只监听本机，不会自动部署到公网。

## 如何操作

| 操作 | 按键或入口 |
|---|---|
| 移动 | **W / A / S / D**，斜向移动不额外加速 |
| 使用携带道具 | **Space**，也可点击底部技能槽 |
| 暂停、继续、查看本局能力 | **Esc** 或“本局能力”按钮 |
| 选择成长卡 | 点击卡片，或 **1 / 2 / 3** |
| 刷新单张卡片 | 卡片下方的“刷新”，每个卡位每轮一次 |
| 音效、玩法说明、全屏 | 页面顶部按钮 |

切出页面会自动暂停。选卡和暂停不计入生存时间；恢复战斗前有 1 秒准备时间。

## 核心玩法

### 敌人与攻击

初始生命为 **1000**，角色没有攻击能力。敌人瞄准当前或预测位置，方向锁定后显示预警；出手后退场，已发出的技能继续存在。

| 攻击 | 伤害 | 应对方式 |
|---|---:|---|
| 长矛 | 100 | 窄而快的直线弹道，向侧面避让 |
| 灼光射线 | 150 | 锁定后约 0.95 秒预警，离开射线范围 |
| 弧形冲击波 | 120 | 宽幅推进，提前寻找绕行空间 |
| 禁锢暗球 | 65 | 定身 0.5 / 1 秒，后期可能出现 2 秒版本 |
| 落星轰击 | 130 | 圆形区域预警后爆炸，及时出圈 |

控制结束后有 1.2 秒防连续定身保护，但仍可能受到伤害。角色显示大小与受击范围采用固定比例，不会随难度改变。

### 难度与操作空间

批次频率、敌人数、弹体速度和施法前摇逐步变化，各自有上限：弹体最快为初始的 1.8 倍，普通前摇最短 1.05 秒，基础批次间隔最短 1.25 秒（有随机浮动），每批最多 9 个候选敌人。攻击伤害不随时间增长。

v3.8 加入全场出招约束：

- 全场最多 **3 个大范围技能**和 **1 个禁锢技能**，计入尚未出手的预约及仍有伤害能力的攻击。
- 大技能关键生效时刻错开约 0.4 秒，超过额度时优先改为窄弹道；总压力过高则跳过出招，不积压补发。
- 大范围技能与禁锢锁定前，对附近路线做有限时间采样，考虑人物速度、控制、边界、现存弹体和已经锁定的攻击。
- 找不到候选退路时跳过本次施法；已显示的预警不会临时转向或更改时间。

**路线检查是基础近似，不保证所有局面都可躲。** 后期组合、难度曲线与成长收益仍需要试玩调优。界面“强度”等级仍每 15 秒增加，但各项参数封顶后不会无限加速。

### 场地道具

| 道具 | 效果 |
|---|---|
| 血包 | 回复最多 180 生命；满血也能拾取并消耗，回复量为 0 |
| 护盾包 | 拾取后按 Space 激活，持续保留，抵挡下一次攻击的伤害及控制后消失；不会解除已生效的定身 |
| 时间减速包 | 按 Space 激活，使长矛、禁锢球、冲击波的飞行速度减半，基础持续 3 秒；不减慢射线、轰击或玩家 |
| 成长碎片 | 收集 3 枚后立即暂停战斗，进入成长选择 |

最多携带一个护盾或减速包，新拾取的技能包会直接替换旧包，同类也可替换，不叠加次数。**拾取新技能包也会移除已经激活的护盾**；血包和碎片不移除护盾。

所有地面物品保留 **8 秒**，有倒计时；拾取时在角色附近显示粒子与飘字。场上最多同时存在一个血包、一个护盾或减速包、一个成长碎片。

| 游戏时间 | 护盾 / 减速尝试间隔 | 血包尝试间隔 | 碎片尝试间隔 |
|---|---|---|---|
| 首次尝试 | 第 12 秒 | 第 18 秒 | 第 4 秒 |
| 0—30 秒 | 12—16 秒 | 16—20 秒 | 9—12 秒 |
| 30—60 秒 | 10—13 秒 | 10—13 秒 | 8—11 秒 |
| 60—90 秒 | 8—11 秒 | 7—9 秒 | 7—10 秒 |
| 90 秒以后 | 7—10 秒 | 6—8 秒 | 6—9 秒 |

护盾和减速共用刷新名额，各有 50% 选择概率；血包和碎片独立刷新。血包不要求残血，也没有额外概率门槛。已有对应物品或没有找到合适位置时跳过当次尝试。补给偏向距玩家较远、靠近危险路线的位置，需要主动争取。

### 成长卡

每 3 枚碎片从六张卡池随机三选一。**成长只在当前一局保留，多种效果可同时生效；新一局全部重置。**

| 卡片 | 每次选择的效果 | 上限 |
|---|---|---:|
| 强健体魄 | 生命上限 +100，并回复 100 | 3 级 |
| 轻盈步伐 | 常驻移速 +4% | 3 级，共 +12% |
| 效果延长 | 时间减速持续时间 +0.5 秒 | 2 级，共 4 秒 |
| 伸手可及 | 拾取范围 +25% | 2 级，共 +50% |
| 护盾疾行 | 护盾格挡成功后，额外加速 15%，持续 2 秒 | 1 级 |
| 时间喘息 | 使用时间减速时回复最多 60 生命 | 1 级 |

每个卡位每轮可以独立免费刷新一次；替换不会影响其他卡片，本轮弃掉的卡不再出现。满级卡不再抽取；剩余候选不足三张时只展示可选项。全部满级后提供“续航储备”：生命上限 +25，并回复 25，避免长局无法完成选择。

第三枚碎片会**立即**弹出卡片页，选择完成后倒计时 1 秒继续战斗。Esc 可查看属性与已选卡等级。

## 本机纪录

按存活时间排序，本机保存最佳 10 局，首页显示前三名。超过开局前的个人最好成绩时会提示新纪录。

成绩保存在浏览器 `localStorage`，更换浏览器、设备、访问地址或清理网站数据可能导致无法读取原成绩。没有账号同步、线上榜单或防作弊。旧版本成绩仍保留，不同规则下的纪录不宜作为严格公平比较。

## 项目结构

```text
.
├── index.html              # 页面、菜单、HUD、成长卡与说明
├── styles.css              # 布局与手绘纸感样式
├── engine.js               # 战斗、碰撞、出招与成长规则
├── game.js                 # Canvas 绘制、输入、反馈、音效与存储
├── dist/dodge-again.html    # 可直接打开的单文件离线版
├── scripts/build-standalone.py
├── tests/                  # 历史回归脚本与调试页面，见其 README
├── TEST-REPORT.md          # 历次验证记录，按版本区分
└── PRODUCT-NEXT.md         # 产品迭代记录及后续方向
```

所有图形通过 Canvas 绘制；音效由浏览器生成，无需下载外部素材或字体。

## 修改与打包

直接编辑源码，刷新浏览器查看效果，无需编译。修改发布版本时同步更新 `index.html` 中的资源版本号，避免旧页面和缓存造成显示不一致。已经打开的页面需要刷新才能载入新代码。

重新生成离线版：

```sh
python3 scripts/build-standalone.py
```

输出为 `dist/dodge-again.html`。

## 验证状态与已知限制

- v3.8 引擎和界面做过 JavaScript 语法检查，**没有完成当前版本的完整回归或多人平衡测试**。
- `tests/` 中包含较早版本测试，部分断言仍针对旧的护盾、血包或攻击逻辑；不是 v3.8 的合格证明，详情见 [`tests/README.md`](tests/README.md)。
- 目前以电脑键盘为主要操作方式，尚未实现触屏移动。
- 后期是否始终有合理退路、卡片是否均衡、补给是否值得冒险，需要继续试玩验证。
- 阶段事件、擦弹奖励、九张卡池、成就和在线排行榜属于后续讨论方向，当前未实现。

项目目前未指定开源许可证。
